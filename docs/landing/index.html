개인정보

내 화면은 어디로 가나요?

기본: 내 Mac 안에서

로컬 OCR과 분류는 외부로 전송되지 않습니다. API 키도 필요 없습니다.

AI를 선택했을 때만

선택한 API 제공자에게 OCR 텍스트가 전송됩니다. ‘이미지 분석’을 켠 경우에만 축소 이미지도 함께 전송됩니다.

삭제는 되돌릴 수 있게

원본을 즉시 지우지 않습니다. 선택한 파일은 macOS 휴지통으로 이동하므로 복구할 수 있습니다.

안전한 설치

공증 릴리스가 준비되면 일반 앱처럼 설치하세요.

공증된 최신 릴리스에서는 shotsort.dmg와 shotsort.dmg.sha256를 함께 받아 checksum을 확인할 수 있습니다.

shasum -a 256 -c shotsort.dmg.sha256
GitHub Release 열기

서명·공증 릴리스가 준비되기 전에는 소스 실행 경로를 이용해 주세요. Gatekeeper 우회 명령은 안내하지 않습니다.

FAQ

설치 전에 알아둘 것

어떤 macOS를 지원하나요?

macOS 13 Ventura 이상을 지원합니다. 로컬 OCR은 macOS Vision을 사용합니다.

업데이트는 어떻게 하나요?

앱이 새 릴리스를 알리면 다운로드 버튼으로 최신 Release를 열어 새 DMG를 설치합니다.

DMG가 바뀌지 않았는지 어떻게 확인하나요?

Release의 .sha256 파일과 함께 받은 DMG에 shasum -a 256 -c 명령을 실행해 OK인지 확인하세요.

유사한 이미지도 찾나요?

CLI의 유사 이미지 검사는 정확히 같은 파일과 시각적으로 가까운 파일을 읽기 전용으로 찾아 줍니다. 삭제는 반드시 명시적으로 선택해야 합니다.

피드백

설치 경험을 알려주세요.

GitHub issue로 보내면 됩니다. 설치 완료로 제출된 수는 install_success, 생성된 feedback issue 수는 feedback_submit의 최소 운영 신호로 집계됩니다. 별도 분석 SDK나 쿠키를 사용하지 않습니다.
